- ESLint、项目清单与通用 JS 构建通过。Windows tgz 解包核对 `os: ["win32"]`、无 CPU 限制、无安装构建钩子和开发依赖，客户端已含 Windows 样式；Host、窗口内宠物、提示音、patch、语言文件与许可证齐全，不包含 macOS 可执行文件，SHA-256 校验一致。
